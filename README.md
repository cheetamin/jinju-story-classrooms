# 우리 지역 이야기 · 동물 유등 공용 전시관

기존 진주 전용 사이트와 별개로 운영하는 학급별 지역 소개 전시관입니다. 원본 소스·운영 DB·학생 작품을 수정하거나 복사하지 않았습니다.

## 사용 흐름
1. 첫 화면에서 `교사용 안내 · 새 학급 만들기`를 선택합니다.
2. 소개할 지역 이름, 학교·학급, 학생 명단, 교사 비밀번호와 학급 코드를 정합니다.
3. 학생은 학급 코드와 개인 비밀번호로 입장합니다.
4. 네 가지 챕터에 지역 소개 작품을 작성·제출합니다. 교사가 승인하면 동물 유등 전시관에서 감상합니다.
5. 교사 관리실의 `지역 설정`에서 지역을 바꿀 수 있습니다. 학생의 기존 글은 자동으로 바뀌지 않습니다.

## 지역 자료
- 진주·진주시·경상남도 진주시: 기존에 정리한 진주 소개 자료를 기본으로 제공합니다.
- 다른 지역: 사실을 임의 생성하지 않고 위치·인물·명소와 축제·특산물의 공통 조사 틀을 제공합니다.
- 교사가 `지역 정보 편집`에서 설명과 HTTPS 이미지 주소를 추가할 수 있습니다.
- 지역 이름을 바꿔도 교사가 저장한 자료는 보존합니다. 이전 지역에서 쓴 자료임을 표시합니다. 현재 지역의 기본 자료로 바꾸려면 확인 후 `기본 내용 불러오기`와 저장을 사용합니다.
- 공통 교사용 예시는 해당 지역 이름으로 만든 조사 방법 예시이며, 원본 진주 학급의 실제 작품을 공유하지 않습니다.

## 현재 검증 / 배포 상태
기능·통합 테스트, TypeScript 검사와 외부 배포용 빌드를 실행했습니다. DB 생성과 실제 Cloudflare 공개 배포는 로그인 연결 이후 진행해야 합니다. 브라우저 화면 QA는 실행 환경의 로컬 미리보기 연결 제한으로 미완료입니다. 아직 공용 버전의 공개 주소는 발급되지 않았습니다.

## 별도 무료 배포
Worker 이름: `our-region-lanterns` / 새 D1 이름: `our-region-lanterns-db`.
`wrangler.external.jsonc`의 DB ID는 안전을 위한 미설정 값입니다. 원본 진주 사이트의 DB ID나 Secrets를 가져오지 마세요.

1. Cloudflare의 Workers Free 계정을 확인합니다. R2 및 유료 구독은 연결하지 않습니다.
2. 새 D1 데이터베이스를 만들고 반환된 ID만 구성에 반영합니다.
3. 새 DB에 `drizzle/`의 마이그레이션 0000~0005를 적용합니다.
4. 전체 관리자 비밀번호와 코드 암호화 키는 새 사이트의 런타임 Secret으로만 설정합니다. Git에 저장하지 않습니다.
5. `npm run build:external` 후 새 Worker에 배포합니다. 기존 진주 Worker에는 배포하지 않습니다.
6. 공개 첫 화면과 서로 다른 지역의 가상 학급 2개로 입장·제작·승인·지역 변경을 검증합니다.

D1-only 보호 한도: 최대 10학급, 파일당 1MB, 학급별 16MB 등 기존 안전 한도가 적용됩니다. 무제한 무료 이용을 보장하지 않습니다.

## 개발
Node 24 이상. `npm test`, `npm run typecheck`, `npm run build:external`.
