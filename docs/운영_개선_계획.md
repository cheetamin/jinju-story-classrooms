# 무료 운영 개선 분석과 실행 계획

기준일: 2026-11-02. 기존 사이트, DB, 파일을 유지한다. 실제 학생 명단과 비밀번호는 이 문서와 GitHub에 기록하지 않는다.

| 그대로 유지 | 추가·보완 |
| --- | --- |
| 픽셀 배경·동물·좌우 순환·반응형 전시 | 이미지 업로드 전 브라우저 압축 |
| D1 학급별 고유 키·역할별 인증·승인본 분리 | 전역·학급별 업로드 차단과 저장 한도 |
| 학생 챕터 편집·임시 저장·PPT/PDF | 교사의 명단·학급 정보 편집과 용량 확인 |
| 공통 교사용 유등·보존 학급 보호 | 코드만 아는 관람객의 학생 이름·작품 접근 제한 |
| 관리자 학교 삭제·별도 인증 | 제한형 독립 배포, GitHub CI, 백업·복구 안내 |

## 확인한 서비스 조건

- 현재는 Sites가 관리하는 Workers + D1(DB) + R2(BUCKET). Sites의 공개 접근 설정을 유지한다. 앱은 ChatGPT 계정이 아닌 학급 코드·개인 인증을 사용한다.
- Sites 공식 안내는 제작/수정 Codex 사용량과 실행·호스팅 사용량을 구분한다. Enterprise 호스팅 면제는 다른 플랜의 영구 무료 보장이 아니다. 연결 도구는 이 계정의 청구·잔여 한도를 제공하지 않는다.
- Workers Free: 하루 100,000요청, 요청당 CPU 10ms. D1 Free: 하루 읽기 500만 행·쓰기 10만 행, 전체 5GB. 무료 한도 초과 시 D1 작업은 실패한다. 인증 해시와 프레임워크의 CPU·번들 한도는 실제 Free 테스트가 필요하다.
- R2 Standard: 10GB-month, 월 A 100만·B 1,000만 회 무료 제공. 무료량 초과 과금 가능하며 활성화는 구독/checkout 절차를 포함한다. 새 R2 구독은 승인 없이 만들지 않는다.
- 엄격한 무결제 시험 배포는 Workers Free + D1에 작은 파일을 저장하는 제한형 옵션을 준비한다. 대형 PPT 파일에는 적합하지 않다. 현재 R2 원본은 옮기거나 지우지 않는다.

## 실행 순서

1. 현재 데이터 보존과 테스트 기준선 확인. 인덱스·추가 테이블만 적용하고 기존 계정/승인본을 초기화하지 않는다.
2. 이미지 압축·저장 한도·업로드/개설 제한·개인 인증·교사 편집을 추가한다. 업로드 중단은 읽기/글 저장을 막지 않는다.
3. 임시 DB에서 교사 2개 학급의 제출/승인·교차 접근 차단, 동시 업로드·한도·기존 데이터 보존을 검증한다.
4. 실명/암호가 포함된 기존 Git 이력을 공개하지 않고 정제된 현재 소스만 새 GitHub 저장소에 게시한다. CI는 검사/빌드만 자동 실행하고 외부 배포는 명시적 수동 실행으로 둔다.
5. 별도 Cloudflare 계정에서 Free 플랜과 D1만 사용하는 시험 배포를 검증한다. 계정 접근·권한 승인·과금 위험이 있으면 중단한다. 기존 Sites 주소를 유지한다.
6. D1 SQL 백업과 비공개 파일 원본 백업을 분리하고 복원은 새 시험 DB부터 진행한다. 백업 파일은 공개 Git에 올리지 않는다. 운영 DB에 파괴적 import를 자동 실행하지 않는다.

## 한계와 비용 위험

앱 내부 용량/요청 수 제한은 공급자의 실제 청구 상한이 아니다. 여러 앱의 계정 합산, 파일 읽기 작업, CPU, DB 쿼리와 CI 분량도 영향을 준다. 현 단계에서 무제한 무료 운영을 보장하지 않는다. 서비스의 무료 제공 조건은 배포 직전에 다시 확인한다.
