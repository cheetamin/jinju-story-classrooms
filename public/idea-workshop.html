01 · I / 문제 인식·탐색IDEA / 02

먼저, 학생이 무엇을 하게 할까요?

“예쁜 전시관 만들기”에 앞서, 학생의 학습 활동을 한 문장으로 정합니다.

이 사례의 수업 목표를 정리하면학생이 우리 지역을 조사하고, 특징과 소개할 이유를 글과 사진으로 표현한 뒤, 친구의 작품을 감상한다.

누구를 위한가?

초등학교 4학년
국어 「지역 소개하기」 활동

어떤 활동을 돕는가?

조사 내용 정리 → 소개 글 작성 → 발표·감상

무엇을 보고 알 수 있나?

지역의 특징과 소개 이유가 작품에 드러나는지, 친구 작품을 보고 새롭게 안 점을 말하는지

30초 생각하기

내가 만들고 싶은 것은 ________ 수업에서, 학생이 ________ 하도록 돕는 도구이다.

성취기준의 정확한 번호·문구와 차시 배치는 교육과정 원문 및 사용하는 교과서와 대조해 입력합니다. 이 자료는 특정 성취기준 번호를 임의로 제시하지 않습니다.

실습 도움말

먼저 내 수업의 목표를 한 문장으로 적어 보세요. 아직 학생에게 적용하지 않았다면 기대하는 효과와 실제로 관찰한 결과를 구분해 기록하세요.

02 · 전체 지도IDEA / 03

IDEA는, 만드는 동안 계속 돌아가는 틀

네 단계마다 남길 결과물이 있으면, AI에게 요청할 내용도 선명해집니다.

단계내가 결정할 것남길 결과물
I Identify
문제 인식·탐색		누가 무엇을 배우며, 어떤 장면에서 도움이 필요한가?학습 목표 1문장 + 학생의 어려움 또는 확인 계획
D Design
설계·기획		어떤 순서로 활동하고, 어떤 화면·기능이 필요한가?화면 흐름 + 첫 프롬프트
E Execute
실행·구현		실행해 보니 요청한 대로 움직이는가?제작본 + 확인 기록 + 수정 프롬프트
A Apply & Assess
적용·평가		수업에 도움이 되는가? 다음에는 무엇을 바꿀까?학생의 실제 말·행동 기록 + 다음 수정점
요청→실행→확인→수정 요청필요하면 I·D로 돌아가기
실습 도움말

실행 중 활동이 너무 복잡하다고 느껴지면 D로 돌아가 순서를 줄이세요. 무엇을 배우는지 모호해지면 I에서 목표를 다시 정하세요.

03 · 진주 전용 → 전국 공용IDEA / 04

실제 사례는 이렇게 커졌습니다

한 번에 모든 기능을 요구하지 않았습니다. 제작한 화면을 보며, 필요를 발견하고 구체화했습니다.

01

이미지와 분위기로 출발

남강과 유등, 귀여운 2D 전시·게임 분위기를 요청

02

학생의 행동을 연결

학생별 동물 유등을 누르면 작품을 감상하는 구조로 구체화

03

글쓰기 제작실 구성

① 지역 소개 ② 역사적 인물 ③ 명소·축제 ④ 특산물의 네 챕터 작성

04

교사 확인 과정 추가

학생 제출 → 교사 승인 → 전시 반영 흐름 정리

05

실행 중 발견한 점 수정

유등의 이동 범위, 한글·영문 코드 입력, 학급 표기, 모바일 화면 등 보완

06

다른 지역으로 확장

진주 전용은 보존하고, 학급별 지역을 설정하는 별도 공용 프로그램 제작

07

공유 후 운영 보완

공개 주소 배포, 학급 개설 한도 조정, 서버 자원 오류에 따른 화면 제공 방식 최적화

위 순서는 제작 기록을 수업용 흐름으로 묶은 것입니다. 개별 작업의 정확한 시간순 기록이나 최초 프롬프트 원문은 아닙니다.

실습 도움말

각 단계에서 “내 수업에도 이 기능이 필요한가?”를 생각해 보세요. 첫 버전의 필수 기능과 사용 후 추가할 기능을 나누어 적으세요.

04 · D / 이미지 참고 요청법IDEA / 05

이미지는 “분위기”를, 글은 “행동”을 설명해요

그림만 주면 버튼을 눌렀을 때의 결과, 저장 방식, 학생·교사의 역할까지 전달되지는 않습니다.

시각적 기준

이미지에서 골라 말하기

① 색과 분위기
② 배경과 요소의 배치
③ 캐릭터의 느낌
④ 화면의 여백과 글자 크기

기능 기준

글로 덧붙이기

① 학생이 하는 일
② 클릭하면 일어나는 일
③ 저장·제출의 순서
④ 바뀌어도 되는 것과 유지할 것

수업용 재구성 · 복사해서 수정하세요
추천: 범용 모델 + 이미지 입력GPT-6.1 Sol 예시

이미지의 분위기와 학생의 활동을 함께 정리하는 단계입니다. 이미지 입력을 지원하는지 먼저 확인하세요.

선택·전환 기준 화면만 설명할 때는 범용 모델로 시작하고, 저장·권한 구조까지 설계하면 고성능 모델로 전환하세요.

첨부 이미지를 참고해 수업용 전시관의 화면을 구상해 줘.

이미지에서 참고할 점: 밤의 강, 따뜻한 유등 빛, 귀여운 2D 분위기, 단순한 메뉴 배치.
새로 만들 점: 학생용 동물 캐릭터와 아이콘.
수업에서 할 일: 학생이 지역 소개 글과 사진을 만들고 친구의 작품을 감상하기.
화면의 핵심: 동물 유등을 누르면 해당 학생의 작품이 열리기.
이동 조건: 유등은 강물 영역 안에서 왼쪽에서 오른쪽으로 흐르기.

먼저 화면 구성과 학생의 활동 순서를 간단히 제안해 줘.

이미지 설명 프롬프트는 실제 요구를 바탕으로 재구성했습니다. 최초 첨부 이미지 원본은 이 자료에 수록하지 않았습니다.

실습 도움말

준비한 참고 이미지에서 가져오고 싶은 점 세 가지를 고르세요. “이런 느낌”을 색·배치·캐릭터처럼 구체적인 조건으로 바꾸어 적어 보세요.

05 · D / 바로 쓰는 기본 틀IDEA / 06

첫 프롬프트는, 이 여섯 칸으로

전문 용어보다, 누가 읽어도 같은 장면을 떠올릴 수 있는 설명이 중요합니다.

1

대상·수업

몇 학년, 어떤 교과·활동인가요?

2

학습 목표

학생이 무엇을 하게 할까요?

3

행동 순서

입장부터 마무리까지 무엇을 누르나요?

4

화면·참고 이미지

어떤 배경·배치·말투가 필요한가요?

5

조건·유지할 것

기기, 필수 기능, 보존할 자료는 무엇인가요?

6

완료 확인

어떤 결과를 확인하면 이번 작업이 끝인가요?

수업용 재구성 · 복사해서 수정하세요

목표·화면·저장·승인 흐름이 서로 맞물리는 첫 뼈대를 설계합니다.

선택·전환 기준 여섯 칸의 문장만 다듬는 일은 경량 모델로 해도 됩니다. 실제 구조를 결정할 때 고성능 모델을 사용하세요.

[대상·수업] ______학년, ______교과의 ______활동

[행동 순서] ______ → ______ → ______ → 마무리
[화면·참고 이미지] __________________
[조건·유지할 것] __________________

먼저 내가 요청한 내용을 짧게 정리하고, 첫 버전에 만들 범위를 제안해 줘.

예: 제출 버튼을 누르면 교사 화면에 ‘승인 대기’로 보인다.

06 · D → E / 완성 예시IDEA / 07

진주 사례의 첫 요청을 다시 써 보면

아래는 당시의 요구를 모아, 여러분이 따라 쓰기 좋도록 다듬은 예시입니다.

수업용 재구성 · 복사해서 수정하세요
추천: 고성능 모델 · 뼈대 제작GPT-6 Astra 예시

여러 화면과 데이터 저장, 학생·교사 역할을 연결해야 합니다.

선택·전환 기준 처음부터 모든 기능을 만들기보다 가상 학생 1명의 작성→승인→감상부터 완성하세요.

초등학교 4학년 국어 「지역 소개하기」 수업에서 사용할 프로그램을 만들어 줘.

1. 목표
학생이 진주의 특징을 조사하고, 글과 사진으로 소개한 뒤 친구의 작품을 감상하게 하고 싶어.

2. 학생 활동
학급 입장 → 내 번호 선택·개인 인증 → 글과 사진 작성 → 임시 저장 → 제출 → 교사 승인 후 전시관에서 감상.
작성 내용은 ① 우리 지역 소개 ② 역사적 인물 ③ 명소·축제 ④ 특산물의 네 챕터로 구성해 줘.

3. 화면
참고 이미지처럼 따뜻한 밤의 강과 귀여운 2D 동물 유등 분위기로 구성해 줘.
학생의 유등을 누르면 그 학생의 작품이 열리게 해 줘.
제작실과 전시관은 별도 화면으로 구성해 줘.

4. 조건
초등학생이 이해하기 쉬운 문구와 큰 버튼을 사용하고, 휴대폰에서도 조작할 수 있게 해 줘.
연습 데이터는 가상 학급과 가상 학생을 사용해 줘.

5. 첫 작업 범위
먼저 가상 학생 1명이 글을 작성하고 제출한 뒤, 교사가 승인하고 전시관에서 여는 흐름부터 구현해 줘.

6. 완료 확인
학생이 임시 저장 후 새로고침해도 글이 남고, 승인한 작품만 전시관에 보이는지 확인해 줘.
완료한 기능·아직 만들지 않은 기능·확인하지 못한 기능을 구별해 알려 줘.

수업용 재구성 예시입니다. 최초에 이 문장을 그대로 입력했다는 의미가 아니며, 후속 정교화에서 나온 조건도 학습을 위해 함께 정리했습니다.

실습 도움말

예시의 각 문장이 여섯 칸 중 어디에 해당하는지 찾아보세요. 내 수업으로 옮길 때는 지역 이름뿐 아니라 학습 목표와 행동 순서도 바꾸세요.

07 · E / 실제 작업 순서IDEA / 08

Work에서는, 요청과 확인을 번갈아 해요

AI가 “완료했습니다”라고 알려주면, 학생의 입장에서 한 번 사용해 봅니다.
